# Pathfinder 1E — encyclopedia pack

Open Game Content paragraphs for the encyclopedia sidebar tool. Not a mechanic catalog.

| File | Contents |
| --- | --- |
| `pack.json` | Manifest. `contentKind: "open-game-content"`. `oglNoticeRequired: true` |
| `entries.json` | Entries joined to CRB or APG rows by id. The only prose field is `body` |
| `OGL-1.0a.txt` | OGL 1.0a license text |
| `SECTION-15.txt` | Which field is Open Game Content, and the sources used |

The CRB and APG folders stay mechanics-only. Do not add `body` there. Do not name a file in this folder `spells.json` or `feats.json`.

See [`docs/sidebar-tools-encyclopedia.md`](../../../docs/sidebar-tools-encyclopedia.md).
